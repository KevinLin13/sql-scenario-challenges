# SQL Scenario Challenges

A PostgreSQL practice repository containing 90 SQL challenges across three business scenarios.

## Scenarios

| Scenario | Challenges | Status |
| --- | ---: | --- |
| Employee Data | 30 | In Progress |
| Coffee Shop | 30 | Not Started |
| Ride Hailing Service | 30 | Not Started |

## SQL Topics

This project covers SQL concepts including:

- SELECT / WHERE / ORDER BY
- Aggregate functions
- GROUP BY / HAVING
- INNER JOIN / LEFT JOIN
- Subqueries
- EXISTS / NOT EXISTS
- Common Table Expressions (CTEs)
- Window functions
- Views
- Set operations

Employee, department, project, assignment, and salary data.

### Coffee Shop

### Ride Hailing Service

## Sources

The exercises in this repository are adapted from Bonnie Chou's SQL challenge series.

- [SQL 練習 30 題：員工資料篇](https://www.bonnie-chou.com/posts/sql-challenges-30-employee-data)
- [SQL 練習 30 題：咖啡廳篇](https://www.bonnie-chou.com/posts/sql-challenges-30-coffee-shop)
- [SQL 練習 30 題：叫車服務篇](https://www.bonnie-chou.com/posts/sql-challenges-30-ride-hailing-service)

The original exercises use SQLite. This repository implements the exercises using PostgreSQL for practice and portfolio purposes.
